# A股指标信号研究 + 每日强信号推送

目标：用历史数据检验常见技术指标信号（均线、MACD、KDJ、RSI、布林、突破、量价、K线形态等）在 A 股是否真的有效，
只把**扣完成本、样本外也站得住**的信号定为“强信号”。之后每天收盘后扫描一次，命中就推送给你，由你手动下单。

## 目录

| 文件 | 作用 |
|---|---|
| `config.yaml` | 股票池、研究区间、成本、强信号门槛、信号单参数（全部口径集中在这里） |
| `common.py` | 路径、成本（印花税/过户费按历史时点取值）、涨跌停规则、成分股映射 |
| `indicators.py` | 指标和 34 个信号事件的定义。**研究和每日扫描共用这一份**，保证回测和推送的信号一致 |
| `fetch_universe.py` | 用 baostock 拉取沪深300/中证500 历史成分股快照（时点一致，减少幸存者偏差） |
| `fetch_prices.py` | 下载后复权日线（新浪为主、腾讯备用）和指数日线，可断点续跑 |
| `analyze.py` | 事件研究 + 截面因子 IC，输出 `results/`：报告、统计表、`strong_signals.yaml` |
| `scan.py` | 每日扫描，按 `strong_signals.yaml` 生成信号单，写入 `signals/` 并推送 |
| `notifier.py` | 推送：默认只打印和写文件；可配置 Telegram / 企业微信 / 飞书 / PushPlus |

## 研究口径（和手动执行方式一致）

- **执行时点**：信号日收盘后出信号，次日开盘买入，持有 H 个交易日后开盘卖出。次日停牌、或开盘即涨跌停（买卖不进）的事件不计入。
- **成本**：
  - 佣金 2.5‱ × 2，滑点 5bp × 2；
  - 印花税：2023-08-28 前 0.1%，之后 0.05%，卖出时收；
  - 过户费：2022-04-29 前 0.002%，之后 0.001%。
- **超额收益**：个股收益减去同一天股票池的等权平均收益。
- **显著性**：先按入场日期聚类，再做 Newey-West 调整。
- **强信号门槛**（全部满足才算）：
  - 持有 5 日；
  - 事件数 ≥ 300，出现在 ≥ 100 个交易日；
  - 全样本 t ≥ 3，样本外 t ≥ 2，样本内外方向一致；
  - 扣成本后超额 ≥ 0.2%；
  - ≥ 60% 的年份方向一致。
- **防未来函数**：随机截断数据重算指标，必须与全量计算完全一致。

## 使用

```powershell
# 一次性：建立研究数据（约 1.5 小时）
..\..\.venv\Scripts\python.exe fetch_universe.py
..\..\.venv\Scripts\python.exe fetch_prices.py
..\..\.venv\Scripts\python.exe analyze.py          # 看 results\report.md

# 每个交易日收盘后（北京时间 15:05 之后；这台电脑时区是 UTC−6，对应本地凌晨 01:05 之后）
..\..\.venv\Scripts\python.exe fetch_prices.py --current-only --refresh --end 20260922
..\..\.venv\Scripts\python.exe scan.py
```

- 持仓清单（可选）：在本目录建 `holdings.yaml`，写 `codes: ["600000", "000001"]`。出现卖出信号时，会标出“你持有”。
- 启用推送：在项目根目录的 `.env` 里配置 `SIGNAL_PUSH` 和对应密钥（见 `notifier.py` 顶部说明），先运行 `notifier.py --test` 测试。
- 研究结果要定期重跑（比如每季度一次）：市场会变，强信号名单也会变。
